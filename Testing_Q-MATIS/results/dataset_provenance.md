# Dataset Provenance

- **Source**: Matbench `matbench_mp_e_form`
- **Date Pulled**: 2026-07-07 23:26:01
- **Train Accepted Row Count**: 16000
- **Test Accepted Row Count**: 4000
- **Train Rejected Row Count**: 5000
- **Methodology**: The dataset was strictly split into train (80%) and test (20%) BEFORE generating rejected candidates. Rejected candidates were ONLY generated by perturbing structures in the training split. This prevents data leakage where a test structure's perturbed sibling appears in the training set.
- **Architecture Note**: We fell back to CGCNN as ALIGNN installation was hanging and unfeasible for the environment.
- **Perturbation Method**: Applied random large displacements (0.5-1.5 Angstrom) and unphysical strains (20-50%) to real structures to generate synthetic rejected candidates. Rejection reasons assigned as 'bond_valence_fail' and 'predicted_unstable'. Note this is a proxy for the experiment, not historical data.
