# Dataset Provenance: Experiment 3 (Thermal Transport)

## Source
- **Base Dataset**: `matbench_phonons` (predicting `last phdos peak` in cm^-1) from Matbench v0.1.
- **Access Method**: Pulled directly via `matminer` bypass (`load_dataset('matbench_phonons')`) since the legacy `matbench` python package fails to compile against modern `scikit-learn` and `numpy`.
- **Dataset Size**: Exactly 1,265 rows. 

## Data Split Strategy
To rigorously address the small sample size and isolate variance sources:
- **Train/Test Split**: We use a deterministic 80/20 train/test split.
  - **Train**: 1,012 structures.
  - **Test**: 253 structures.
- **Deterministic Fix**: The split is seeded strictly with `random_state=42` and executed precisely once. The exact structure IDs assigned to the test set have been saved to `split_indices.json`.
- **20-Seed Reusability**: All 20 experimental seeds (42–61) use this identical test set. The random seed inside the dataset generator is only used to control model initialization, training batch order (data loader shuffling), and the random perturbations applied to generate rejected structures. 

## Rejected Candidate Generation (Leakage Guard)
- **Ratio**: A 1:1 ratio of accepted to rejected structures is maintained in the training set (1,012 accepted, 1,012 rejected).
- **Perturbation Source**: Rejected structures are generated by randomly substituting or perturbing atoms from the **training set only**. 
- **Leakage Check**: A strict programmatic `assert` guarantees no test-set structures are ever used as parent templates for rejected candidates. The log is maintained in `leakage_check.md`.
- **Dedup Cache**: The Phase 0 `DedupCache` ensures all generated rejected structures are physically unique, preventing silent dataset duplication.
