# Preregistration: Q-MATIS Experiment 2 (Scientific Memory Hypothesis)

## Hypothesis
Run B (accepted+rejected, rejection-reason-aware) achieves lower test MAE on formation energy than Run A (accepted-only), same architecture, same seed, same number of accepted-material training examples.

## Decision Threshold
Run B must beat Run A by at least **3% relative MAE reduction** to count as support for the Q-MATIS thesis. Less than that (including Run B being worse) counts as a null/negative result.

## Commitment
We commit to reporting the result honestly either way. A negative result is a valid, useful outcome — we will not reframe or cherry-pick metrics after seeing the numbers to manufacture a positive story.
